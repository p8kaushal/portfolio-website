# Phase 4 — changing-room prototype

The enhanced mirror opens an on-demand view of the existing project-owned procedural character, with shared About content. A separate renderer draws the character against a static room backdrop within a large frame. Pointer or touch dragging pans; labelled buttons provide pan, zoom and reset, including keyboard access. Classic retains the existing illustrated mirror. If the portrait WebGL context cannot initialize or is lost, the illustrated mirror and About content remain available. Closing the dialog releases the portrait renderer and its own resources; the house retains ownership of the shared character geometry and materials.

The existing procedural character is the starting point, not a newly approved likeness. The original reference photographs were not found in the project inventory. User likeness review is pending; this document and prototype checkpoint do not finalize Phase 4.

A separate feasibility prototype rendered the enhanced house through Three.js `Reflector` at 512². On local headless Chromium at a stationary wardrobe view and Balanced quality, frame interval p95 was 66.7 ms without the reflector and 100.1 ms with it; CPU render-call p95 was 0.2 and 0.5 ms respectively. This is a comparative local experiment, not GPU timing or a production budget pass. The on-demand portrait is the lower-cost static-backdrop alternative; it does not reflect the current house or visitor dynamically. See `phase-4-evidence/reflection-prototype.json`.

Fresh sequential `npm run check` (zero errors and warnings) and `npm run build` passed. The production browser test exercised desktop keyboard and pointer, emulated touch drag and controls, reset, About, exit, forced portrait context loss and reopening, and denied portrait context initialization. It reported no page errors. With the dialog open, local stationary p95 frame intervals were 33.4 ms desktop and 16.8 ms emulated mobile; these do not establish physical-device performance. Existing production scene switching/recovery and classic and enhanced source interaction suites passed. Captures and reports are in `phase-4-evidence/`.

The mirror dialog now keeps the character visible while About scrolls independently. A fresh production test verified the visible frame after scrolling in desktop, emulated mobile portrait and landscape, plus the classic mobile mirror. The latest open-dialog p95 intervals were 33.4 ms desktop and 16.7 ms in both emulated mobile orientations. These remain local headless measurements.

The wardrobe approach now has a woven runner, vertical light details and brass trim, with no additional collision bounds. A fresh check/build, production four-room day/night suite and changing-room interaction/recovery suite passed. The inspected wardrobe capture is retained in `phase-4-evidence/wardrobe-day.png`.
